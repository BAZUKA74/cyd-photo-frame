# CYD PhotoFrame

Прошивка и Android-приложение для Wi-Fi фоторамки **ESP32-2432S028 / HW-458** с экраном 320×240.

## Возможности

- загрузка фото, GIF и MP4 с телефона;
- оптимизация файлов под память ESP32;
- LIVE-рисование по Wi-Fi;
- кисти, цвета и перемещаемый текст;
- сенсорное меню, поворот и заполнение экрана;
- ручная и автоматическая яркость;
- обновление Android-приложения через GitHub Releases.

## Скачать приложение

Последний APK находится в разделе [Releases](https://github.com/BAZUKA74/cyd-photo-frame/releases/latest). Android попросит подтвердить установку обновления.

## Важно: другие платы

> Готовая прошивка предназначена для **ESP32-2432S028 / HW-458**. У похожих плат могут отличаться контроллер дисплея, разрешение, распиновка, тачскрин, подсветка и объём Flash. Не загружайте готовый BIN в неизвестную плату вслепую.

Код можно адаптировать вручную или при помощи ИИ. Для этого подготовьте:

1. фотографии обеих сторон платы;
2. полную маркировку платы и ESP-модуля;
3. модель контроллера дисплея и тачскрина;
4. распиновку или ссылку на схему;
5. размер Flash и наличие PSRAM;
6. разрешение и нужную ориентацию экрана;
7. лог компиляции или загрузки, если есть ошибка.

### Готовый запрос для ИИ

> Адаптируй проект CYD PhotoFrame под мою плату. Не меняй сетевой протокол и функции Android-приложения. Сначала проверь контроллер экрана, разрешение, объём памяти и всю распиновку. Затем измени конфигурацию PlatformIO и прошивку. Не предлагай прошивать BIN от HW-458 напрямую.

Подробная памятка находится в [ADAPTATION.md](ADAPTATION.md).

## Безопасный порядок адаптации

1. Считайте и сохраните полный заводской дамп Flash.
2. Проверьте питание и уровни GPIO.
3. Соберите тест только с заливкой экрана одним цветом.
4. Проверьте тачскрин, подсветку и датчики.
5. Затем добавляйте Wi-Fi, GIF и LIVE-рисование.

## Исходники

Архив `CYD-PhotoFrame-v1.6-source.zip` содержит:

- `firmware/` — проект PlatformIO для платы;
- `android/` — исходники Android-приложения;
- конфигурацию разделов Flash;
- эту документацию и инструкцию по адаптации.

Закрытый ключ подписи APK намеренно не публикуется. Все обновления должны подписываться тем же ключом, иначе Android не установит их поверх предыдущей версии.
